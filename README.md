# KuoteX — Next-Gen Sandbox Messenger

An innovative, privacy-focused messenger combining a high-performance communication platform with an embedded sandbox environment for application development.

## 🚀 Key Features

* **Crypto-Protected Protocols:** Secure and encrypted end-to-end messaging.
* **Embedded IDE:** In-app sandbox allowing users to build, script, and launch custom micro-apps.
* **AI Ecosystem:** Integrated AI agents driven by Moshi conversational models.
* **Advanced Content Streams:** Support for channels, group chats, live streaming, voice messaging, and automated channel boosts.
* **Global Monetization Engine:** Production-ready multi-gateway billing: Stripe, ЮKassa, SberPay, DonationAlerts, and Ko-Fi.
* **Idempotent Transactions:** Bulletproof payment state management preventing duplicate billing.

## 🛠 Tech Stack

* **Frontend:** Kotlin (Jetpack Compose / Android SDK), Java
* **Backend:** Python (FastAPI/Flask/Asyncio), Moshi AI integration
* **Infrastructure & Automation:** Bash/Shell scripting, Firebase, Gradle (Kotlin DSL)

## 🏗 Architecture & Automation

The project utilizes an automated patch-delivery pipeline (`/scripts`) to dynamically inject authentication layers, component modifiers, and platform-specific feature flags during the build process, maximizing codebase flexibility.
